# イベント予報の定義（events.json）

トップページの「イベント」行に表示するイベントの一覧は、
`public/events.json`で定義します。リストからイベントを選んで
「開催地の予報を表示」を押すと、開催地の予報が表示されます。

開催地は**郵便番号**で指定します。座標は画面側が
`GET /api/geocode`（郵便番号→市区町村名→座標）で解決するため、
緯度経度を調べる必要はありません。

## 書き方

`public/events.json`の`events`配列にイベントを追加します。

```json
{
  "events": [
    {
      "name": "けもケット17",
      "place": "TRC東京流通センター",
      "zip": "143-0006",
      "startDate": "2026-09-20",
      "startTime": "12:00",
      "endTime": "17:00"
    },
    {
      "name": "Kemocon 19",
      "place": "御殿場高原　時之栖",
      "zip": "412-0033",
      "startDate": "2026-11-06",
      "endDate": "2026-11-08",
      "startTime": "15:00",
      "endTime": "21:00"
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|------|------|------|
| `name` | 必須 | イベント名（空文字は不可。重複も不可） |
| `place` | 必須 | 開催場所の表示名（会場名など。空文字は不可） |
| `zip` | 必須 | 開催地の郵便番号（`143-0006`または`1430006`） |
| `startDate` | 必須 | 開催初日（`YYYY-MM-DD`形式） |
| `endDate` | 任意 | 開催最終日（`YYYY-MM-DD`形式、省略時は`startDate`と同じ=単日開催） |
| `startTime` | 任意 | 開催初日の開始時刻（`HH:MM`形式） |
| `endTime` | 任意 | 開催最終日の終了時刻（`HH:MM`形式） |

`startTime`・`endTime`を書いておくと、開催日の予報を表示したときに
**活動プランナーへ開催時間が自動で設定されます**（終了時刻は時間単位へ
切り上げます。19:30終了なら20時まで）。複数日開催で中日にあたる日は
終日開催として扱います。

## 画面での動き

- イベントは**開催が近い順**に並びます
- **終了済みのイベントは自動的に表示されなくなります**
  （`endDate`、単日なら`startDate`が過ぎたもの。定義から消す必要は
  ありませんが、増えてきたら整理してください）
- 開催日（開催中なら今日、これからなら初日）が予報の範囲内
  （今日から3日間）に入っていれば、予報の表示後に**その日のタブへ
  自動で切り替わります**
- 開催日がまだ予報範囲外の場合は、開催地の直近の予報を表示し、
  開催までの日数を案内します（開催が近づいてから再度選ぶと開催日の
  予報が見られます）
- 郵便番号から開催地を特定できなかった場合は、その旨を表示します
  （郵便番号の誤りが疑われます）
- 定義が空・読み込み失敗のときは、イベント行のセレクトとボタンが
  無効のまま（その旨の表示）になります

## 予報の地点の精度について

郵便番号は市区町村名を経由して座標へ変換されるため、解決される地点は
**会場そのものではなく市区町村の代表点**になることがあります。予報は
約5kmメッシュのため通常は問題ありませんが、市域が広い自治体や山間部
（標高差が大きい場所）では、会場付近の実際の気象と差が出ることが
あります。会場ピンポイントで確認したい場合は、地点検索や現在地から
表示してください。

## 反映のしかた

`public/events.json`を編集してmainへマージすると、自動デプロイで
本番へ反映されます。GitHubのWeb画面から直接編集してPRを作る方法が
簡単です。

## 検証

形式の誤り（必須項目の欠落・郵便番号や日付の書式誤り・終了日が開始日
より前・イベント名の重複など）は`test/events.test.ts`がCIで検出します。
フロントエンドも必須項目や書式が不正な項目は黙って表示から除外するため、
1件の定義ミスで画面全体が壊れることはありませんが、「登録したのに
表示されない」を避けるためPRのCI結果を確認してください。
