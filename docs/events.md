# イベント予報の定義（events.json）

トップページの「イベント」行に表示するイベントの一覧は、
`public/events.json`で定義します。リストからイベントを選んで
「開催地の予報を表示」を押すと、開催地の予報が表示されます。

## 書き方

`public/events.json`の`events`配列にイベントを追加します。

```json
{
  "events": [
    {
      "name": "サンプルコン2026",
      "place": "東京ビッグサイト",
      "lat": 35.6297,
      "lon": 139.7947,
      "startDate": "2026-08-22",
      "endDate": "2026-08-23"
    },
    {
      "name": "もふもふ集会",
      "place": "大阪城公園",
      "lat": 34.6873,
      "lon": 135.5262,
      "startDate": "2026-09-05"
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|------|------|------|
| `name` | 必須 | イベント名（空文字は不可） |
| `place` | 必須 | 開催場所の表示名（会場名など。空文字は不可） |
| `lat` | 必須 | 開催地の緯度（`-90`〜`90`の数値） |
| `lon` | 必須 | 開催地の経度（`-180`〜`180`の数値） |
| `startDate` | 必須 | 開催初日（`YYYY-MM-DD`形式） |
| `endDate` | 任意 | 開催最終日（`YYYY-MM-DD`形式、省略時は`startDate`と同じ=単日開催） |

座標は[国土地理院地図](https://maps.gsi.go.jp/)などで会場を指して
調べられます。予報は約5kmメッシュのため、小数2桁（約1km）程度の
精度で十分です（画面のURLに現れる座標は小数2桁へ丸められます）。

## 画面での動き

- イベントは**開催が近い順**に並びます
- **終了済みのイベントは自動的に表示されなくなります**
  （`endDate`、単日なら`startDate`が過ぎたもの。定義から消す必要は
  ありませんが、増えてきたら整理してください）
- 開催日（開催中なら今日、これからなら初日）が予報の範囲内
  （今日から3日間）に入っていれば、予報の表示後に**その日のタブへ
  自動で切り替わります**
- 開催日がまだ予報範囲外の場合は、開催地の直近の予報を表示し、
  範囲外である旨をステータスに案内します（開催が近づいてから
  再度選ぶと開催日の予報が見られます）
- 定義が空・読み込み失敗のときは、イベント行のセレクトとボタンが
  無効のまま（その旨の表示）になります

## 反映のしかた

`public/events.json`を編集してmainへマージすると、自動デプロイで
本番へ反映されます。GitHubのWeb画面から直接編集してPRを作る方法が
簡単です。

## 検証

形式の誤り（必須項目の欠落・座標や日付の書式誤り・終了日が開始日より
前など）は`test/events.test.ts`がCIで検出します。フロントエンドも
不正な項目は黙って表示から除外するため、1件の定義ミスで画面全体が
壊れることはありませんが、「登録したのに表示されない」を避けるため
PRのCI結果を確認してください。
