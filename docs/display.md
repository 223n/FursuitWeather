# 会場表示モード（display.html）

イベント会場のモニターへ着ぐるみ天気予報を常時掲示するための
自動表示ページです。次の4枚のスライドを自動で切り替えながら、
予報を定期的に更新し続けます。

| スライド | 内容 | 表示秒数 |
|---------|------|---------|
| いまの判定 | 現在時刻の判定・天気・気温・活動目安・WBGT | 15秒 |
| この後の予報 | 今後6時間の時間別（天気・気温・判定） | 20秒 |
| 3日間の天気 | 日別サマリー（天気・気温・最悪判定・洗濯） | 15秒 |
| 全国の天気 | 主要12都市の天気・最高気温・判定 | 20秒 |

どのスライドが表示されていても、画面上部の帯に「現在の判定」
（記号+ラベル+連続活動時間の目安）が常に表示されます。

## URLの作り方

トップページで会場の地点を表示し（検索・郵便番号・都市の選択いずれでも）、
「会場表示モードで開く」を押すと、その地点を引き継いだ会場表示ページが
新しいタブで開きます。会場のパソコンには、開いたページのアドレスバーの
URLをコピーして渡してください。

URLパラメータ（すべて任意）:

| パラメータ | 説明 |
|-----------|------|
| `lat`・`lon` | 表示する地点の座標（小数2桁へ丸められます） |
| `name` | 画面に表示する地点名（80文字まで）。表示専用で、座標との整合は検証されません |
| `demo` | `1`で上流に接続しないデモ表示（設営リハーサル用） |
| `theme` | `light`で、端末のOS設定がダークモードでも明色で表示 |

地点を指定しないと東京の予報を表示し、画面に「地点が指定されていません」
の注意が出続けます。**本番前に必ず座標付きのURLで開いてください。**
会場表示のURLは必ず運営者自身がトップページの「会場表示モードで開く」から
発行し、他者から受け取ったURL・QRコードをそのまま掲示に使わないでください
（`name`は表示専用のため、座標と食い違う地点名を名乗るURLに画面上では
気付けません）。

## 設置手順（会場での準備）

1. **時刻合わせ**: 端末の時計を自動同期（NTP）にしてください。
   「いまの判定」は端末の時計で時間帯を選ぶため、時計が狂うと
   別の時間帯の判定が大きく表示されます（大きくずれている場合は
   画面に警告が出ます）
2. **初回は必ずオンラインで開く**: 一度正常に表示されると、以後は
   回線が切れても直前の予報で表示を続けられます（保存済みの表示には
   その旨の注意が出ます）
3. **全画面表示**: F11キー（Windows）またはキオスクモード
   （例: `chrome --kiosk <URL>`）で全画面にしてください
4. **スリープ無効化**: ページ自体も画面スリープ防止（Wake Lock）を
   要求しますが、確実に表示し続けるにはOS側の設定でスリープと
   スクリーンセーバーを無効にしてください
5. **リハーサル**: `?demo=1`を付けたURLで、上流の気象データ取得や
   当日の天気に関係なく表示の確認ができます（本サイトへの接続は必要です。
   手順2のとおり一度オンラインで開いた端末なら、回線が切れていても
   確認できます）

## 表示・更新の仕様

- 表示地点の予報は約11分ごと、全国の天気は約31分ごとに再取得します。
  画面右下の「HH:MM時点」はデータの生成時刻です（取得した時刻ではありません）
- 取得に失敗しても直前のデータで表示を続けます。データが1時間以上
  古くなると「この表示は◯◯:◯◯時点の情報です。最新の予報を取得できて
  いません。」という注意が画面に出ます。画面右下の時刻表記とこの注意は、
  データが前日以前のものになった場合は日付付き（例「8/18 14:30時点」）で
  表示されます
- 毎日深夜4時台に自動で再読み込みし、アプリの更新の反映とメモリの
  回収を行います（オフライン時や最新の予報を取得できていない間は見送り、
  翌日以降の回復後に行います）
- 熱中症警戒アラートの基準（暑さ指数33以上）に相当する予測のときは、
  警戒の帯が出続けます。これは推定値による表示で、環境省の発表その
  ものではありません
- 焼き付き対策として表示全体を数分ごとに1pxずらしていますが、
  有機EL等のモニターでは夜間の電源オフを推奨します

## 操作（設置者向け）

掲示中の操作は不要です。以下は設置・案内時の補助操作です。

- 「次へ」ボタン・画面タップ・左右矢印キー: スライドを手動で送る
  （15〜20秒後に自動送りへ戻ります）
- 「一時停止」ボタン: 自動送りを止める（「再開」を押すまで止まったまま。
  停止中も上部の帯に現在の判定は表示され続けます）

## 推奨環境

- モダンブラウザ（Chrome・Edge・Firefox・Safariの最新版）+
  キオスクモードでの利用を推奨します。個別のセットトップボックスや
  テレビ内蔵ブラウザでの動作は保証しません
- 目安として、フルHD（1920×1080）の40型モニターで視距離5m程度までを
  想定した文字サイズです。より遠くから見せる場合は大きな画面を
  使用してください
