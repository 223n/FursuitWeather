# FursuitWeather（着ぐるみ天気予報）

> FursuitWeather（着ぐるみ天気予報）のトップページのMarkdown版です。
> HTML版: <https://fursuit-weather.223n.tech/>

気象庁モデルの気象データから、着ぐるみ（fursuit）で活動するのに適しているかを予報する無料のWebサービスです。暑さ指数（WBGT）に着ぐるみの着衣補正（+11℃）を加えた5段階の判定と、連続活動時間の上限の目安を、最大4日先まで1時間ごとに表示します。

トップページの予報は、ブラウザで地点を選んだあとにJavaScriptで描画するため、このMarkdown版には予報の値は含まれません。機械的に予報を取得するときは、下の「予報データの取得」にあるAPIを使ってください。

## 判定の見方

段階は色だけでなく、記号と文字の組み合わせで表しています。

| 記号 | 判定 | 連続活動時間の目安 |
|---|---|---|
| ◎ | ほぼ安全 | 連続45分まで。適宜水分補給を。 |
| ○ | 注意 | 連続30分まで。積極的に水分補給を。 |
| △ | 警戒 | 連続20分まで。ヘッドを外して冷却を。 |
| ✕ | 厳重警戒 | 連続10分以内。冷房環境へ退避を。 |
| （禁止マーク） | 危険 | 着用中止。熱中症の危険が非常に高い状態。 |
| ○（温度計マーク） | 低温注意 | 低温側は温度計マーク付き。凍結・汗冷えに注意。 |

時間別予報の風速は、10m/s以上（気象庁の「やや強い風」以上）のときに強調します。判定の根拠としきい値は[判定の仕組み](https://fursuit-weather.223n.tech/about#how-it-works)をご覧ください。

## 活動時の注意

- 着ぐるみ内は冬でも数分で発汗する高温多湿環境です。季節を問わず熱中症対策が必要です。
- 必ず2人以上で行動し、着用者以外の付き添い（ハンドラー・アテンド）を付けてください。
- 表示の連続活動時間は気象条件から見た上限の目安です。「30分着たら30分休む」を基本に、吐き気・めまい・頭痛を感じたら直ちに脱いでください。
- 本予報は目安です。体調や装備により安全な活動時間は変わります。最終判断はご自身で行ってください。

熱中症が疑われるときの応急対応は[もしものとき](https://fursuit-weather.223n.tech/emergency)にまとめています。

### しばらく着ていない人へ（暑熱順化について）

体が暑さに慣れる「暑熱順化」は7日以上かけて得られ、おおむね4日以上暑さから離れると失われ始めます。数週間ぶりの活動では、真夏と同じ感覚で着ると熱中症のリスクが高くなります。再開の初日は計画の目安のおよそ半分から始め、数回かけて段階的に延ばしてください（[根拠と出典](https://fursuit-weather.223n.tech/about#acclimatization)）。

## トップページでできること

- **地点の選択**: 主要12都市・イベント（登録済みイベントの開催地）・都市名や郵便番号の検索・現在地・お気に入りから選べます
- **いまの判定**: 現在時刻の屋外・屋内の判定、暑さ指数（着ぐるみ補正後）、連続活動時間の目安
- **3日間の天気・日別の天気**: 日別サマリーと時間別予報（降水確率・風速付き）、洗濯乾燥指数、静電気・空気のよごれ（黄砂・PM2.5）の指数
- **活動プランナー**: 日付と時間帯を選んで、その間の判定をまとめて確認できます
- **実測WBGT**: 会場のWBGT計で測った値から判定します
- **当日の運用**: 見守りモード（画面を開いている間、10分ごとに自動更新）、コンディションチェック、着用タイマー、複数の着用者を見守る当日ボード
- **共有**: 表示中の地点の共有URL、印刷用シート、画像での共有、会場表示モード（イベント会場のモニター向け）

現在地は約1kmの精度に丸めたうえで予報の取得のみに使い、保存しません。最後に表示した地点とお気に入りは、利用者のブラウザ内にのみ保存します（詳しくは[この端末に保存されるもの](https://fursuit-weather.223n.tech/about#privacy)）。

## 予報データの取得

- 予報API: `GET https://fursuit-weather.223n.tech/api/forecast?lat=35.68&lon=139.68`（認証不要・CORS対応）
- API一覧（RFC 9727のAPIカタログ）: <https://fursuit-weather.223n.tech/.well-known/api-catalog>
- API仕様: [docs/api.md](https://github.com/223n/FursuitWeather/blob/main/docs/api.md)・[OpenAPI定義](https://github.com/223n/FursuitWeather/blob/main/docs/openapi.yaml)
- サービスの概要（AI向け）: <https://fursuit-weather.223n.tech/llms.txt>

大量アクセスはデータ提供元（Open-Meteo）の無料枠を圧迫するためお控えください。
