# 会場表示モード（FursuitWeather）

> FursuitWeather（着ぐるみ天気予報）の「会場表示モード」ページのMarkdown版です。
> HTML版: <https://fursuit-weather.223n.tech/display>

イベント会場のモニターへ掲示するための自動表示ページです。着ぐるみ活動の判定と天気予報を、スライドショーで自動で切り替えながら、予報を定期的に更新し続けます（掲示中の操作は不要です）。

表示内容はブラウザでJavaScriptが描画するため、このMarkdown版には予報の値は含まれません。予報を機械的に取得するときは、[予報API](https://fursuit-weather.223n.tech/about#api)を使ってください。

## スライド

- **いまの判定**: 現在時刻の判定・天気・気温・活動目安・WBGT
- **この後の予報**: 今後6時間の時間別（天気・気温・判定）
- **3日間の天気**: 日別サマリー（天気・気温・最も厳しい判定・洗濯）
- **全国の天気**: 主要12都市の天気・最高気温・判定
- **もしものとき**: 熱中症の応急対応の要点。設定でONにしたとき、または屋外判定が厳重警戒以上の間は自動で巡回に加わります

どのスライドが表示されていても、画面上部の帯に現在の判定（記号・ラベル・連続活動時間の目安）が常に表示されます。

## 開き方

トップページで会場の地点を表示し、「会場表示モードで開く」を押すと、その地点を引き継いだ会場表示ページが開きます。URLパラメータ（すべて任意）で地点や表示内容を指定することもできます。

| パラメータ | 説明 |
|---|---|
| `lat`・`lon` | 表示する地点の座標（小数2桁へ丸められます） |
| `name` | 画面に表示する地点名（80文字まで） |
| `demo` | `1`で上流に接続しないデモ表示（設営リハーサル用） |
| `slides` | 表示するスライド（`now`・`hours`・`days`・`national`のカンマ区切り。`emergency`を含めると「もしものとき」が常時巡回に加わる） |

設営前のチェックと設置手順、そのほかのパラメータは、[会場表示モードの使い方（docs/display.md）](https://github.com/223n/FursuitWeather/blob/main/docs/display.md)を参照してください。
